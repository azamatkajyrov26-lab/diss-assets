# diss-assets (ВРЕМЕННЫЙ репозиторий)

Файлы для достройки дашборда прогнозирования академического риска (модуль LMS).
Диссертацию НЕ трогаем — задача только про дашборд-страницы и скриншоты.

⚠️ **УДАЛИТЬ ПОСЛЕ ИСПОЛЬЗОВАНИЯ.**

## Файлы
- `data/metrics.json` — канонические метрики моделей.
- `dashboard/index.html`, `dashboard/student-detail.html` — существующий дашборд (расширять поверх).
- `code/` — исходники (генерация данных, обучение, FastAPI, heatmap-трекер).
- `screenshots/dashboard.png`, `screenshots/student-detail.png` — старые demo-скрины (числа неверные).
- `screenshots/real-lms/` — реальные скрины LMS (содержат имена — анонимизировать перед публикацией!).
- `PROMPT.md` — задание для агента.

## Задание
См. `PROMPT.md`. Кратко: достроить 4 страницы дашборда с реальными числами и снять скриншоты в `screenshots/dashboard-new/`.
