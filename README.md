# diss-assets (ВРЕМЕННЫЙ репозиторий)

Вспомогательные файлы для добавления рисунков/визуалов в магистерскую диссертацию.

⚠️ **УДАЛИТЬ ПОСЛЕ ИСПОЛЬЗОВАНИЯ.** Репозиторий содержит черновик диссертации
(`dissertation.docx`) — не оставлять публично надолго (риск для проверки на антиплагиат).

## Файлы
- `dissertation.docx` — документ-источник правды (редактируется).
- `data/metrics.json` — **канонические** метрики моделей (совпадают с текстом).
- `dashboard/index.html`, `dashboard/student-detail.html` — существующий дашборд (расширять поверх).
- `code/` — исходники для Приложения Г.
- `screenshots/dashboard.png`, `screenshots/student-detail.png` — старые demo-скрины (демо-числа, НЕ использовать как есть).
- `PROMPT.md` — задание для агента.

## Чего здесь НЕТ (намеренно)
Реальные скриншоты LMS (login / lesson plan / журнал / группы) **не выложены** — на них
настоящие имена студентов (перс. данные). Их владелец добавит в Приложение В локально.
